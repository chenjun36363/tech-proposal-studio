## 二、LIMS和无人实验室的接口

### 2.1 接口验证权限的Key

本次对接为我方LIMS与无人实验室，每次调用接口需要附带key，用于验证是否是无人实验室的身份。

- 方案：专门给无人实验室分配一个专用key，此key没有失效时间，可以一直调用
- 传输方式：key + 时间戳，约定一个加密方式，将【key+时间戳】整体加密，接收时解密验证

只有确认此key传输的数据才属于LIMS与无人实验室数据对接的信息内容。

### 2.3 LIMS接收无人实验室的样品分析结果

无人实验室将样品分析完毕后，通过接口将数据传回LIMS：

| 信息 | 举例 |
|---|---|
| 样品编号+分组名称 | 水260202004化学需氧量、氨氮、总氮 |
| 待分析的测试项目 | w01019 |
| 检测结果 | 0.336 |
| 结果涉及的报告 | Postid |

> 此部分的接口，施光豪前阵子已经基本写完了，具体参考 2.4。注意接口中有个postid为 2.4中分析结果报告的附件相关联。

#### 上传检测结果数据接口（批量）

**接口说明**：批量上传分析数据，与上传的文件通过 postId 关联。

- **请求方法**：POST
- **请求路径**：/api/upload/data
- **Content-Type**：application/json

**请求参数**

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| postId | string | 是 | Uuid编码，与上传文件接口的postId对应 |
| datas | array | 是 | 数据数组 |

**datas 数组结构**

```json
[
  {
    "sampleName": "水260202004总磷",
    "analyzeItemName": "W0001",
    "value": 1.61
  },
  {
    "sampleName": "水260202004化学需氧量、氨氮、总氮",
    "analyzeItemName": "W0003",
    "value": 2.61
  }
]
```

**字段说明**

| 字段名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| sampleName | string | 是 | 样品编号 |
| analyzeItemName | string | 是 | 分析项目名称 |
| value | number | 是 | 浓度值，浮点数类型 |

**请求示例**

```bash
curl -X POST "http://api.example.com/api/upload/data" \
  -H "Content-Type: application/json" \
  -d '{
        "postId": "123e4567-e89b-12d3-a456-426614174000",
        "datas": [
          {
            "sampleName": "水260202004总磷",
            "analyzeItemName": "W0001",
            "value": 1.61
          },
          {
            "sampleName": "水260202004化学需氧量、氨氮、总氮",
            "analyzeItemName": "W0003",
            "value": 2.61
          }
        ]
      }'
```

> 此部分的接口，施光豪前阵子已经基本写完了，具体参考如下。注意接口中有个postid为 2.4中分析结果报告的附件相关联。

#### 上传检测结果文件接口

**接口说明**：用于上传单个文件到系统。

- **请求方法**：POST
- **请求路径**：/api/upload/file
- **Content-Type**：multipart/form-data

**请求参数**

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| postId | string | 是 | Uuid编码，用于关联后续的数据上传 |
| fileName | string | 是 | 上传文件的原始名称 |
| file | file | 是 | 上传的文件内容（二进制数据） |

**请求示例**

```bash
curl -X POST "http://api.example.com/api/upload/file" \
  -F "postId=123e4567-e89b-12d3-a456-426614174000" \
  -F "fileName=test_data.xlsx" \
  -F "file=@/path/to/your/file.xlsx"
```

**响应结构**

```json
{
  "success": true,
  "code": "200",
  "msg": "文件上传成功"
}
```

**响应码说明**

| code | 说明 |
|---|---|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 权限不足 |
| 500 | 服务器内部错误 |
