# **项目建设背景**

为进一步加强监测机构监管，提升检测数据质量，市场监管总局、生态环境部于2025年12月联合制定出台了《检验检测机构资质认定生态环境监测机构评审补充要求（2025年）》（国市监检测规【2025】4号），并明确于2026年1月1日起正式施行。这是自2021年以来，国家对检验检测机构资质认定条件的又一次重大修订，充分体现了国家对检验检测质量的高度重视和对检验检测机构监管的持续加力。

《补充要求（2025年）》共二十一条内容，从人员、设备、设施、质量管理体系等多个维度对检验检测机构提出了全面、具体、严格的要求。与此前版本相比，2025年版补充要求最显著的变化在于将实验室信息管理系统（LIMS）从以往的“推荐配置”提升为“必备条件”，这一调整具有划时代意义，标志着LIMS系统从“可选项”变为“必选项”，成为检验检测机构取得和维持CMA资质的硬性条件。

为实现检验检测决策科学化、管理可视化和服务便捷化，提升检验检测管理能力现代化水平，顺应信息化浪潮和数字化改革需求，无锡市生态环境监测监控中心应建立一个信息化的实验室信息管理系统覆盖全无锡市各分中心1+2+4模式的全检测业务，用于管理检测项目的进展情况，对实验室进行高质量的管理。

# **建设价值**

<a id="_Toc7466"></a>
## 第1章 **满足CMA资质认定合规要求的迫切需要**

《检验检测机构资质认定生态环境监测机构评审补充要求（2025年）》（国市监检测规〔2025〕4号）已于2026年1月1日起正式施行。该补充要求最显著的变化在于将实验室信息管理系统从过去的“加分项”或“可选项”升级为关乎资质存续的“必选项”和“核心合规基础设施”。其第十七条明确规定：“监测机构应使用信息管理系统，对监测过程中的数据和信息进行管理”，要求系统覆盖合同/委托书签订、方案制定、样品采集、现场测试、样品保存、样品流转、样品制备和前处理、分析测试、结果计算、报告编制等全流程。同时，新规进一步强调“使用时应采用系统直接采集数据的方式”，并要求“监测中由仪器设备直接采集和输出的数据、谱图、日志等，应优先以不可更改的电子记录形式保存”。

<a id="_Toc22646"></a>
## 第2章 **打破信息孤岛、实现全市监测资源高效协同的迫切需求**

《生态环境监测条例》明确要求“建立健全生态环境监测数据汇交制度和集成共享机制”。本次提供的LIMS服务正是要构建全市统一的手工监测任务管理平台和资源调度体系，打通市中心-分中心两级手工监测的业务流和数据流。在资源统筹方面，建立覆盖全市各分中心的人员资质库、仪器设备台账、标准物质与试剂耗材库存、方法标准库及环境条件监控的全要素资源图谱，实现资源的统一编码、集中管理和智能调度。在任务统筹方面，将市级年度生态环境监测方案逐级分解为各机构的可执行任务包，通过系统实时追踪采样进度、分析进度、数据上报进度和报告编制进度。平台支持超期预警、异常自动识别等功能，使管理部门能够及时发现问题、精准调度资源、科学评估绩效，推动手工监测管理从“静态报表”向“动态可视”、从“事后统计”向“实时掌控”、从“经验驱动”向“数据驱动”的全面升级。

<a id="_Toc21221"></a>
## 第3章 **构建全市统一监测标准规范、保障数据一致可比的关键路径**

当前，全市监测业务流程分散、标准执行不一，存在数据溯源难、质控薄弱等问题。《补充要求（2025年）》从人员配置、设备规范、过程管控、责任落实等方面提出了更严标准与更高要求。同时，新规将检验检测项目划分为水、空气、土壤、固体废物等13个监测类别，规定监测机构申请任意一个类别资质时，应当具备该类别全部检测能力。

依托一体化平台服务，建立统一的监测标准规范和质量管理体系，整合各类监测数据，健全量值溯源体系，保障不同部门、不同区域同类监测数据的一致性、可比性。南通市已建成运行生态环境监测全链条监测平台，实现了市中心-分中心统一资源库管理、统一监测流程、统一质控要求、统一报告模板、统一数据报送方式。无锡市本次构建的LIMS服务将参照此类成熟经验，通过统一的基础资源库（方法标准、监测对象等）和数据治理入库，确保全市范围内“同一项目、同一标准、同一尺度”，推动《补充要求（2025年）》标准规范在全市有效落地。同时，系统需对监测活动全要素进行监管，实现生态环境监测活动全流程可追溯。

# **技术功能方案**

<a id="_Toc30838"></a>
## 第6章 **“1+2+4”区域一体化实验室信息管理系统**

无锡市区域一体化生态环境监测实验室信息管理系统采用“1+2+4”一体化运行模式，即1个市监控中心与2个分站、4个分中心，纳入同一平台统一管理。系统基于“市级统建、分级应用、数据隔离”的设计原则，各监测机构在统一的业务规范和质量体系框架下独立运行，实现“业务统一、数据隔离”的集约化管理模式。

实现全市生态环境监测业务的标准化、流程化与信息化管理，全面覆盖业务委托、监测方案制定、现场采样、样品流转、实验室分析、数据审核、报告编制与签发等监测业务全流程。系统设计紧密结合无锡市中心及各分中心的实际工作需求，全面支撑环境监测工作的全流程闭环管理，提升监测质量和管理效率。

<a id="_Toc3021"></a>
### 6.1 **监测业务管理子系统**

监测业务管理子系统是系统的核心业务引擎，实现对生态环境监测全流程的数字化闭环管控。功能覆盖业务委托、合同评审、任务下达、采样准备、现场采样、样品登记、数据录入与复核、数据审核、数据汇总、报告编制、审核与签发等关键环节。

<a id="_Toc2722"></a>
### 6.2 **实验室资源管理子系统**

围绕实验室质量管理体系要求，对影响监测质量的关键要素进行全面管理，包括人员资质与培训、仪器设备状态、标准物质和试剂耗材的使用、检测能力范围、实验环境条件以及受控文件等。

<a id="_Toc21379"></a>
### 6.3 **基础配置管理子系统**

为满足不同监测业务场景的需求，系统提供灵活的配置功能，支持自定义监测任务类型、样品类型、检测模板、样品分瓶规则、编号规则、报表样式及工作流程等基础参数设置。增强系统的适应性与扩展性，确保平台能够根据实际业务变化进行快速调整。

<a id="_Toc6388"></a>
### 6.4 **统计管理子系统**

统计管理子系统为各监测机构提供本机构运行态势的全面查询与统计分析能力。系统聚焦本机构内部的监测任务、样品流转、检测数据、人员绩效等核心管理要素，包括任务执行进度、样品检测状态、人员工作量统计等维度。通过多维度的数据查询与分析展示，辅助本机构管理人员全面掌握监测工作整体运行状态，为内部任务调度与绩效考核提供科学的数据支撑。

<a id="_Toc22482"></a>
### 6.5 **质控管理子系统**

质控管理子系统是将质量控制措施深度嵌入监测业务全流程的核心支撑模块。系统依据预设质控规则与评价标准，对采样、分析、数据审核等各环节实施全过程质量监控，实现质控数据自动计算、智能评价、异常预警与闭环处理，确保监测数据的准确性、精密性、可比性与可追溯性，全面满足CMA资质认定对质量管理体系的信息化要求。

<a id="_Toc24406"></a>
### 6.6 **现场监测移动端**

现场监测移动端支持项目流程类和应急类任务的全流程管理，现场人员可通过移动终端下载或新建监测任务，确认样品清单、建立采样单、添加质控样、现场打印标签，并实时与LIMS平台交互信息；系统支持现场数据记录，包括监测数据、仪器使用、环境信息、经纬度定位及现场拍照上传；同时提供基于项目编号、名称或受检单位等条件的历史数据查询功能，便于现场人员及时掌握监测点位动态。

<a id="_Toc26465"></a>
### 6.7 **电子报表模块**

#### 6.7.1 电子采样记录单模块

系统应支持电子现场记录单生成并且结合电子签章进行表单无纸化流转。电子现场记录单需根据不同检测项目自动绑定检测项目及标准方法、现场采样环境参数、使用仪器设备、仪器校准信息、采样方法及相关技术依据、现场仪器采集或填写的检测数据及最终结果、质控样数据等信息，并且支持现场生成、打印。

#### 6.7.2 电子原始记录单模块

系统应支持电子原始记录单生成并且结合电子签章进行表单无纸化流转。电子原始记录单需自动绑定检测项目及标准方法、实验过程中的环境、使用仪器（含仪器型号、编号、检定和校准有效期）、前处理信息、运用的校准曲线、标定记录、标准溶液配制记录、分析过程中包括仪器自动采集的检测数据及最终结果、质控样信息等多方面数据，能够保证电子原始记录单数据的审核路径、数据安全、完整性、操作记录等要求。

#### 6.7.3 电子报告模块

提供各类监测报告模板的管理，支持模板的创建、编辑、分类和版本控制。系统预置水质监测、大气监测、土壤监测、噪声监测、委托检测等标准模板，管理人员可在标准模板基础上根据业务需要进行组件快速调整。

<a id="_Toc29358"></a>
### 6.8 **实验室仪器数据采集模块**

系统支持与仪器进行无缝衔接，自动采集与处理分析数据，将仪器产生的图谱文件采集到实验室管理系统中，并对图谱文件进行解析后自动匹配，减少数据录入工作量，避免录入误差，提高工作效率。

通过上传仪器工作站生成的仪器原始报告文件（PDF、XLS、TXT等）,系统根据文件中的数据内容，自动获取检测原始数据（峰面积、浓度、响应值等），无需人工抄录。采集数据自动关联：采集的数据自动匹配对应的样品编号、监测项目及分析批次，减少人工关联操作。

<a id="_Toc10477"></a>
## 第7章 **全市监测资源库**

建立覆盖全市各级监测机构的人力资源、仪器设备、方法标准、监测业务等基础资源数据库，实现资源统一管理与动态调度，为全市生态环境监测业务的规范运行和科学决策提供坚实的数据底座。全市监测能力资源库主要包括监测能力资源库、方法标准资源库、监测业务资源库三大类，具体功能如下：

<a id="_Toc30317"></a>
### 7.1 **监测能力资源库**

监测能力资源库是全市监测机构核心能力的集中管理平台，涵盖机构信息、监测能力、人员档案、设备档案、上岗证及标准物质等关键要素，为质量管理、资源统筹和资质维护提供基础数据支撑。

<a id="_Toc4904"></a>
### 7.2 **方法标准资源库**

建立全市统一的环境保护标准资源库，对生态环境监测涉及的现行国家及行业标准予以结构化、标准化管理，涵盖水、气、噪声、土壤、固废、生态保护、环境影响评价及其他环境保护标准。方法标准可分为环境质量标准、污染源排放标准、环境监测规范/方法标准等类别，为合同评审、方案制定、实验室分析、结果评价等业务环节提供统一的标准依据，确保全市各级监测机构执行统一的技术规范和质量标尺。

<a id="_Toc27513"></a>
### 7.3 **监测业务资源库**

监测业务资源库是支撑全市监测业务常态化运行的基础业务数据集合，涵盖环境质量点位、水体信息、污染源企业、污染源点位、样品类型、量纲等核心业务字典，为监测方案编制、采样安排、数据归类统计和结果评价提供统一的数据基础。

<a id="_Toc23662"></a>
## 第8章 **全市监测监管服务平台**

于“1+3”区域一体化实验室信息管理系统，构建覆盖全市、统一协同的生态环境监测监管体系。通过对市中心及各分中心检测任务、质控活动与专项工作的全流程数据汇聚与闭环管理，实现从业务执行到质量评价的标准化、透明化监管，为提升全市生态环境监测数据的准确性与公信力提供核心支撑。

<a id="_Toc19335"></a>
### 8.1 **年度监测计划管理**

年度监测计划管理模块是全市年度生态环境监测工作从目标分解、任务落地到执行监控、成果归档的全过程数字化管理工具。市中心各要素部门依据市级年度生态环境监测方案，登记发布年度监测目录；各分中心基于目录编制详细监测计划，明确监测点位、监测频次及监测项目等内容；市中心要素部门可实时追踪各机构任务执行进度，调阅监测成果数据，实现对全市年度监测工作“目标下达—计划编制—执行监控—成果调阅”的闭环管理。

<a id="_Toc26949"></a>
### 8.2 **综合业务统计**

本模块基于区域一体化实验室信息管理系统，汇聚市中心及各分中心的监测任务、样品、数据、报告、质控、人员与设备等全要素信息，提供统一的综合查询、统计分析与实时监控功能，支撑全市生态环境监测业务的全局监管与决策分析。

<a id="_Toc31774"></a>
## 第9章 **实验室专题**

数据全面源自全市实验室监管平台，旨在构建覆盖实验室资源、监测业务与数据质量的一体化监管视图，为实验室体系的管理效能与数据可靠性提升提供决策支持。

<a id="_Toc14279"></a>
### 9.1 **区域一体化专题**

依托无锡市生态环境监测网络数据，构建“全市统筹·市市联动·资源可视”的区域一体化实验室管理驾驶舱。系统以动态可视化看板为核心载体，实现对全市监测资源与业务运行状态的全景式监管。

<a id="_Toc16092"></a>
### 9.2 **“一站一档”专题**

基于实验室信息管理系统的基础数据，建立监测机构的标准化电子档案。该专题以单个为核心对象，通过可视化界面集中展示该机构的资质能力、资源配置及运行状态，实现对单体站点信息的数字化管理与快速查询。

## 第10章 **第三方检测服务机构监管系统**

该系统构建了“备案-活动”的全生命周期闭环监管模式。在备案阶段，第三方机构需在线填报资质、人员、设备等详细信息，监管部门进行线上审核与动态管理，确保入口合规。在检测活动监管阶段，系统要求机构将承接的检测任务关键节点信息，如采样地点（含GPS定位与现场照片）、检测数据、出具报告等，同步至监管平台。这使得监管人员能够远程监督采样过程的规范性，并对上报的数据进行在线核验与逻辑性审查。

<a id="_Toc30562"></a>

确保"1+2+4区域一体化实验室信息管理系统"、与全市其他环保信息系统等各平台与应用间数据的无缝流转与业务的高效协同，需构建一套标准化、规范化、安全可靠的数据接口体系。

## 第13章 **功能特点、优异行、先进性**

**1、远大公司简介及功能模块**

江苏远大信息股份有限公司成立于2002年，公司专注于环境监测LIMS的研发，自2006年开始至今已有20年，LIMS产品发展到第6代，公司总部张家港，员工280人，新三板上市公司。

远大实验室信息管理系统产品线丰富，目前已有20个子系统模块，涵盖了实验室监测业务管理、质量管理体系、移动现场监测业务、区域一体化管理、社会化检测机构管理、AI智能应用等，LIMS相关软件著作权30余项。

远大LIMS具有完全的自主资识产权，满足用户的个性化开发需求及灵活流程配，扩项、内审、外审表单修改调整方便快捷，满足信创国产化架构保证数据安全。

**2、参与制定上海LIMS团体标准及符合补充要求**

远大公司是“生态环境监测实验室信息管理系统建设技术指南T/SSESB0000

0202-2021”的起草单位，并于2020年9月3日与上海市环境监测中心一起去生态环境部监测司作了汇报。满足新发布的《检验检测机构资质认定生态环境监测机构评审补充要求（2025）》。

**3、现场仪器数据采集及黑灯实验室数据采集**

已实现现场仪器数据采集，基于现有的现场监测设备，通过智采终端实现对现场数据的自动采集，并在现场数据录入时，自动获取仪器数据。已实现与黑灯实验室实现系统对接，实现对黑灯实验室数据的自动获取，并生成原始记录单。

**4、AI应用**

基于检测业务一体化管理平台，融合自然语言处理（NLP）、语义理解、知识图谱与数据可视化等先进技术，分为“问数”与“问答”两大核心功能模块，全面支撑环境监测业务中的数据分析与知识服务需求，显著提升数据利用效率与技术水平。通过“问数”与“问答”双轮驱动，AI智能问答系统实现了数据价值挖掘与知识服务能力的深度融合，推动环境监测工作向智能化、知识化方向发展，为构建智慧生态环境管理体系提供坚实的技术支撑。

**5、检测能力库**

基于区域一体化监测业务管理系统和生态环境监测实验室信息管理系统，远大公司已积累了丰富的数据资产，可为系统的快速落地上线提供帮助。已建立的检测能力信息库，涵盖4000项以上的检测能力库，覆盖水质监测、环境空气与废气监测、土壤监测、固废监测、噪声监测、电磁辐射等各类监测方法标准，满足各个监测方法标准的公式计算、修约规则、质控要求、质控评价、有效期限等。一体化平台涵盖现场监测记录单30份，实验分析原始记录单约100份，报告模板约15份，且经过多地验证并得到认可。

远大公司于2021年12月至2022年12月为无锡市生态环境监控中心建设了“环境质量自动监测监控系统”项目，覆盖环境质量水、气监测站点，为生态环境业务监管提供了有效的技术保障与支撑。

未来将全市实验室信息管理系统手工监测数据与全市环境质量自动监测数据有效整合，实现环境监测数据、污染源监管数据、共享数据等各类数据资源的统一采集、标准治理和高效服务。在大数据应用、治理层面，建立覆盖数据全生命周期的质量管控体系与标准规范，形成可管理、可追溯、可评价的数据资产目录。
