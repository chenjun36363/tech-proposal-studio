# 上海固废LIMS招标方案（中简版）

以下是进一步丰富但又不至于过于冗长的各模块描述：

### 第1章 项目概述

- **1.1 项目背景** ：随着社会对生态环境要求不断提高，上海市固体废物处置有限公司为实现环境监测管理决策科学化、管理可视化和服务便捷化，提升环境监测管理能力以顺应信息化和数字化改革需求，拟建立一套信息化的实验室信息管理系统（LIMS 系统），用于全面管理监测项目的进展情况，进而实现对实验室的高质量管理。
- **1.2 相关技术标准规范** ：本项目严格遵循包括 RB/T 028《实验室信息管理系统管理规范》、RB/T 029《检测实验室信息管理系统建设指南》、ISO/IEC 17025《检测和校准试验室能力通用要求》、RB/T214《检验检测机构资质认定能力评价检验检测机构通用要求》、HJ 630《环境监测质量管理技术导则》、GB/T8170《数值修约规则与极限数值的表示和判定》、GB/T 28035《软件系统验收规范》、HJ728《环境信息系统测试与验收规范》以及 HJT419《环境数据库设计与运行管理规范》在内的多项相关技术标准规范。
- **1.3 建设内容** ：涵盖了从多个子系统到硬件设备的全方位建设内容。具体包括检测业务管理子系统、实验室资源管理子系统、基础配置管理子系统、统计管理子系统、质控管理子系统、现场监测移动端、电子原始记录单模块、电子采样记录单模块、电子报告报表模块、实验室仪器数据采集模块、上海社会化监管平台对接、大型分析仪器数据采集、质量管理体系子系统、移动审批子系统、领导驾驶仓各 1 套，以及服务器 2 台、台式标签打印机 2 台、便携式标签打印机 2 台、标签纸和碳带耗材若干。

### 第2章 系统建设要求

- **2.1 检测业务管理子系统** ：将传统手工项目委托工作流程转变为网络化办公模式，统筹规范实验室内各部门用户的工作流程，实现从订单、任务及方案编制、审核、接样，到样品分析、数据录入、复核、分析报告审批等多个环节的全流程管理，促进信息最大化使用和实验室工作流程规范化。

  - **2.1.1 订单管理** ：业务人员可全面录入订单信息，并能按任务来源、性质进行分类管理，详细记录业务类型、订单名称、业务人员、订单日期、报价期限、客户等多维度信息。支持添加订单明细，系统依据检测项目的采样单价、分析单价自动计算检测总费，同时允许手动修改最终报价，审核人员可查看订单明细并进行审核操作。
  - **2.1.2 任务及方案编审** ：任务承接人负责登记任务基本信息并编制方案。对于采样类任务，可根据现场情况及委托要求编制监测方案，系统依据方案自动生成任务单；送样类任务则可直接添加样品，建立样品编号及检测项目信息。
  - **2.1.3 审核下达** ：技术负责人对监测方案等信息进行审核，审核通过后，采样类任务流转至采样部门，送样类任务流转至样品管理员。
  - **2.1.4 现场采样** ：采样前系统生成采样瓶标签，支持增加现场平行、空白样和加标样，采样人员可记录现场采样信息、监测数据和仪器使用记录并提交审核。
  - **2.1.5 样品接收** ：样品管理员进行样品交接，系统记录样品交接详细信息，涵盖接收人员、性状、运输条件、时间及数量等。
  - **2.1.6 留样处置** ：提供样品留样和处置功能，可填写留样日期、保存位置等，记录处置日期、方式和人员。
  - **2.1.7 分配任务** ：样品接收后系统自动分配任务到分析测试岗位人员，分析主管可手动调整检测方法和人员，上岗证过期人员无法进行分析任务。
  - **2.1.8 数据录入** ：分析人员建立检测任务单、录入分析数据等，系统能自动生成校准曲线并参与样品浓度计算，支持公式配置自动计算检测数据，可添加质控记录并具备提醒报警功能。
  - **2.1.9 数据审核** ：对分析完成的数据进行复核和审核，支持电子原始记录单、电子签名生成功能，完整记录审核日志。
  - **2.1.10 报告编制签发** ：依据 RB/T 214 要求生成报告编号及电子报告，支持一个任务生成多份报告，报告环节提供数据查询和项目档案信息查看功能，报告提交后按工作流配置发送至相关人员审核签发，签发通过后生成含电子签名且不可编辑的报告副本。
  - **2.1.11 报告归档** ：打印授权签字人审核通过的报告，支持报告发放与回收功能，详细记录领取人、发放时间、快递单号等信息。
- **2.2 实验室资源管理子系统** ：实现对实验室各类资源的全面管理，包括人员档案、仪器设备、方法标准、评价标准、消耗品、标准溶液配制、文件、客户、分包商等。

  - **2.2.1 人员管理** ：全面管理人员档案信息，涵盖姓名、工号、所属科室等，对上岗证进行细致管理，开设人员账号并合理设置角色权限，人员离职后及时禁用账号，确保系统安全。
  - **2.2.2 仪器设备管理** ：维护仪器设备的详细信息，包括维修维护、检定等履历信息，自动生成仪器使用记录，及时提醒仪器检定计划等，全方位确保仪器状态正常，具备严格的仪器出入库功能。
  - **2.2.3 方法标准管理** ：系统化管理所有检测能力，无论是否通过认证 / 认可的分析方法均涵盖在内，精准设定方法静态配置信息，支持方法作废和替换功能，保证检测方法的时效性和准确性。
  - **2.2.4 评价标准管理** ：灵活设置评价标准的编号、名称、评价条件及限值要求，实现对照不同标准进行准确评价，满足多样化的检测需求。
  - **2.2.5 消耗品管理** ：对试剂、耗材和标准品进行分类管理，详细查看消耗品信息，进行日常管理操作，合理设置报警条件，实时记录领取消耗品的相关信息，实现消耗品的精细化管理。
  - **2.2.6 标准溶液配制管理** ：维护标准溶液配值信息，完整记录配制过程等，确保标准溶液的准确性和可追溯性。
  - **2.2.7 文件管理** ：提供文档的创建、存储、查询和共享功能，涵盖程序文件、质量手册、作业指导书等各类文档，方便文件的管理和利用。
  - **2.2.8 客户管理** ：详细登记客户基本信息，包括企业名称、法人等，方便与客户进行业务往来和沟通。
  - **2.2.9 分包商管理** ：对分包商信息进行全面统一管理，支持上传附件，便于对分包商的相关资料进行存档和查看。
- **2.3 基础配置管理子系统** ：具备灵活的配置功能，可对任务类型、流程、编号规则等信息进行配置，同时管理样品类型基本信息，设置工作流引擎参数，配置测试公式计算逻辑及参数，设定报表模版和生成规则，以适应实验室不断变化的业务需求。
- **2.4 统计管理子系统** ：全方位对实验室的各种信息进行统计分析，包括项目进度、样品、送样单、检测单、数据、归档报告等的查询功能，以及项目数量、人员工作量等的统计功能，为实验室的管理和决策提供有力的数据支持。

  - **2.4.1 项目进度查询** ：实时呈现项目详细信息及所处状态，支持通过项目信息内关键字进行模糊查询项目详情，方便生成监测任务台账，及时掌握项目整体进展情况。
  - **2.4.2 样品查询** ：用户可按多种条件搜索样品，全面查看样品的相关信息及交接、领取记录，实现样品的全程追溯。
  - **2.4.3 送样单查询** ：根据设定条件便捷查询送样单信息及样品检测状态，便于对送样情况进行管理和跟踪。
  - **2.4.4 检测单查询** ：按相应条件快速查询检测单信息，提高检测单管理的效率。
  - **2.4.5 数据查询** ：依据设定条件查询监测任务数据，方便对监测数据进行分析和利用。
  - **2.4.6 归档报告查询** ：查询归档报告信息，实现对检测报告的分类管理，方便用户快速查找所需报告。
  - **2.4.7 项目数量统计** ：精准统计任意时间段内各类委托数量及样品数量，为业务量分析提供数据依据。
  - **2.4.8 人员工作量统计** ：详细统计分析人员、采样人员、报告编制人员的工作量，为人员绩效评估和工作分配提供参考。
- **2.5 质控管理子系统** ：完善实现质控考核、数据质控、质控样品统计、质控分析统计等功能，全方位保障检测数据的质量和准确性。

  - **2.5.1 质控考核** ：灵活下达质控考核任务，涵盖实验室比对、能力验证等多种形式，系统汇总数据结果，辅助质量管理人员进行深入分析评价。
  - **2.5.2 数据质控** ：精准设置质控评价标准，自动计算相关指标并进行评价，及时提醒不满足要求的数据，确保数据质量可控。
  - **2.5.3 质控样品统计** ：对采样样品添加现场平行样等，检测人员录入数据后，系统自动计算质控结果，方便查询质控样品详细信息，实现质控过程的可追溯性。
  - **2.5.4 质控分析统计** ：全面查询质控样品信息，详细统计质控数据，包括分析项目、人员、现场采样数等，为质控管理提供有力的数据支持。
- **2.6 现场监测移动端** ：集成项目流程类任务管理、应急类任务管理、现场数据记录、数据查询等功能，提升现场监测工作的效率和便捷性。

  - **2.6.1 项目流程类任务管理** ：现场监测人员下载监测任务，查看样品信息，确认样品清单，建立采样单，添加质控样，打印样品标签，与 LIMS 平台交互信息后采集样品，确保现场监测工作的规范性和准确性。
  - **2.6.2 应急类任务管理** ：现场监测人员根据现场实际情况登记应急任务详情，同步至 LIMS 系统，实现对应急监测任务的快速响应和有效管理。
  - **2.6.3 现场数据记录** ：详细记录现场监测数据、仪器和环境信息，精准获取经纬度，进行拍照拍摄，同步至 LIMS 平台，确保现场数据的完整性和真实性。
  - **2.6.4 数据查询** ：便捷查看历史数据信息，包括项目、采样单、样品数据等，方便现场监测人员及时掌握现场监测点位动态，为后续工作提供参考。
- **2.7 电子原始记录单模块（标准版）**  ：支持生成电子原始记录单，结合图片签名实现无纸化流转，自动绑定检测项目及标准方法、实验环境、仪器信息等多方面数据，涵盖多种常见分析方法的原始记录表单，提高实验室数据记录的效率和规范性。
- **2.8 电子采样记录单模块（标准版）**  ：支持生成现场采样电子记录单，结合图片签名实现无纸化流转，自动绑定检测任务信息、采样样品及点位信息等多方面信息，包含多种采样场景的记录表单，确保现场采样记录的完整性和准确性。
- **2.9 电子报告报表模块（标准版）**  ：支持生成电子版监测 / 检测报告，结合图片签名实现无纸化流转，自动生成功能性报表，报告可绑定丰富信息并显示 CMA 和 CNAS 章，满足不同用户的报告需求，提升报告的权威性和可信度。
- **2.10 实验室仪器数据采集模块** ：将仪器图谱文件采集至实验室管理系统，解析后上传数据，实现与仪器的无缝衔接，自动采集处理分析数据，有效减少人工录入工作量和误差，提高工作效率和数据准确性。
- **2.11 上海社会化监管平台对接** ：预留数据对接功能接口，与上海环境监测中心社会化服务监管平台实现稳定对接，依据 API 接口推送规定内容，确保监测数据的及时共享和监管要求的满足。
- **2.12 大型分析仪器数据采集** ：与站内的不少于 10 台大型仪器设备进行数据对接，同步实验结果数据至 LIMS 平台，实现大型分析仪器数据的集中管理和高效利用，提升实验室的整体检测能力。
- **2.13 质量管理体系子系统** ：构建完善的质量管理体系，涵盖年度计划管理、不符合项管理、内审计划管理、客户投诉管理等功能。

  - **2.13.1 年度计划管理** ：系统制定各类年度计划，将其合理下发分解为分步计划，明确责任人，实时跟踪执行过程，确保计划的全面落实和有效执行。
  - **2.13.2 不符合项管理** ：实现对不符合项的全生命周期管理，包括及时登记、深入原因分析、制定纠正措施、有效验证等环节，持续改进质量管理工作。
  - **2.13.3 内审计划管理** ：全流程管控内审计划，从编制、审核、执行到确认、评审等环节，确保内审工作的规范性和有效性。
  - **2.13.4 客户投诉管理** ：全方位管理客户投诉，涵盖登记、审核、处理、反馈等流程，实现投诉处理过程的可追溯性，不断提升客户满意度。
- **2.14 移动审批子系统** ：审批人借助移动终端设备上的应用，对监测任务的多个关键业务环节进行便捷审核批准，打破时间和空间限制，显著提高业务办理和流转效率，加速工作进程。
- **2.15 领导驾驶仓** ：汇总 LIMS 中的关键数据，通过直观的模块化看板进行展现，实时反馈业务状态与实验室效能，客观体现站内业务及工作状态。支持年度数据的深入分析比对展示，利用柱状图、网图等图形化方式突出展示各类数据及成果，关键信息经脱敏处理后便于投屏展示，为领导决策提供有力的数据支持和直观的视觉体验。
- **2.16 硬件设备参数** ：配备服务器 2 台，品牌为戴尔，型号为 R550；台式标签打印机 2 台，打印方式为热转印 / 热敏，分辨率≥203dpi，速度≥102mm/s，最大打印宽度≥104mm；便携式标签打印机 2 台，采用行式热敏打印，行宽≥72MM，纸张为热敏纸，数据通讯接口支持串口 RS232 蓝牙，一次充电续航 100-150M，切纸方式为手切纸；以及适配的标签纸、碳带耗材若干。

### 第3章 项目管理、实施、培训及其他要求

- **3.1 项目组织管理要求** ：通过科学合理的管理措施，充分保证项目实施的范围控制、进度控制和质量控制，确保项目按计划顺利推进并达到预期目标。

  - **3.1.1 系统培训** ：为系统管理员和使用人员提供全面且有效的系统使用、配置等技术培训服务，采用现场指导培训、现场培训会议等多种方式，结合演示、操作、示范等多种教学手段，确保培训人员能够熟练掌握系统的操作和应用。
  - **3.1.2 系统验收方案** ：明确项目验收里程碑，包括测试通过版本安装部署、完成对系统使用用户和系统管理员的培训工作、验收资料移交至用户方、满足采购合同及定制化需求中的技术要求和使用要求等关键节点，规定复审和批准程序，确保项目验收的严谨性和规范性。
  - **3.1.3 售后服务** ：提供一年的免费质保服务，保障软件平台的稳定运行和正常使用，及时解决出现的 BUG 和突发故障。工作日 5×8 小时提供电话、即时通讯等故障响应服务，重大故障时采用远程接入等方式快速排查解决，建立完善的分故障级别的快速响应机制，配备专业的技术服务维护人员，为系统的长期稳定运行提供坚实的售后支持。
