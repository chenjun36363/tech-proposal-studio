# 远大LIMS无人实验室数据交互接口说明

## 概述

在实验室信息管理系统（LIMS）中完成样品登记与任务分配后，无人实验室能够通过调用样品查询接口及检测项查询接口，获取所需检测的相关信息。

检测过程在无人实验室内部完成后，通过数据推送接口将检测结果数据进行推送。该推送机制支持数据的多次及批量推送。

用户在LIMS系统中既可实现检测数据的自动同步更新，亦可选择性地手动提取特定检测结果数据，作为实验分析的结果。

---

## 1. 查询样品接口

无人实验室可通过"查询样品接口"查询样品待检信息。该接口支持根据样品编号、样品名称、采样日期等条件进行查询，返回样品的详细信息。

| 序号 | 数据项名称 | 数据项编码 | 字段类型 | 示例 | 说明 |
| ---- | ---------- | ---------- | -------- | ---- | ---- |
| 1 | 样品ID | SampleID | String | `123e4567-e89b-12d3-a456-426614174000` | 唯一标识样品的编号 |
| 2 | 样品编号 | SampleNumber | String | SN20240507001 | 样品的编号，用于标识样品 |
| 3 | 样品名称 | SampleName | String | 水样1 | 样品的具体名称 |
| 4 | 采样日期 | SamplingDate | Date | 2024-05-07 | 样品采集的日期 |
| 5 | 采样经度 | SamplingLongitude | Float | 116.397428 | 采样点的经度坐标 |
| 6 | 采样纬度 | SamplingLatitude | Float | 39.90923 | 采样点的纬度坐标 |
| 7 | 分瓶号 | BottleNumber | String | B1 | 样品分瓶的编号 |
| 8 | 测试项合集 | TestItems | String | pH、COD、BOD | 样品需要检测的项目集合 |
| 9 | 样品状态 | SampleStatus | String | 待检、已检、异常 | 样品当前的状态 |
| 10 | 创建日期 | CreateDate | Date | 2024-05-07 | 样品信息创建的日期 |
| 11 | 更新日期 | UpdateDate | Date | 2024-05-08 | 样品信息最后更新的日期 |

---

## 2. 查询检测项接口

无人实验室可通过"查询检测项接口"查询检测任务信息。该接口根据样品ID返回与该样品相关的检测任务的详细信息。

| 序号 | 数据项名称 | 数据项编码 | 字段类型 | 示例 | 说明 |
| ---- | ---------- | ---------- | -------- | ---- | ---- |
| 1 | 测试项ID | TestItemID | String | `123e4567-e89b-12d3-a456-426614174001` | 唯一标识检测项的编号 |
| 2 | 样品ID | SampleID | String | `123e4567-e89b-12d3-a456-426614174000` | 对应样品的ID |
| 3 | 测试项名称 | TestItemName | String | pH检测 | 检测项目的名称 |
| 4 | 分析人员 | Analyst | String | 张三 | 负责分析的人员姓名 |
| 5 | 分析方法名称 | AnalysisMethodName | String | 比色法 | 采用的分析方法的名称 |
| 6 | 方法标准编号 | MethodStandardNumber | String | GB/T 12345-2020 | 分析方法对应的标准编号 |
| 7 | 检测状态 | TestStatus | String | 待检、进行中、已完成 | 检测任务的当前状态 |
| 8 | 创建日期 | CreateDate | Date | 2024-05-07 | 检测任务创建的日期 |

---

## 3. 结果数据推送接口

无人实验室可通过"结果数据推送接口"推送检测结果数据。样品复测产生的相同样品的数据，仅上传1条为最终结果。该接口支持批量推送。

| 序号 | 数据项名称 | 数据项编码 | 是否必填 | 字段类型 | 示例 | 说明 |
| ---- | ---------- | ---------- | -------- | -------- | ---- | ---- |
| 1 | 数据ID | DataID | 是 | String | `123e4567-e89b-12d3-a456-426614174002` | 唯一标识检测结果的编号 |
| 2 | 测试项ID | TestItemID | 是 | String | `123e4567-e89b-12d3-a456-426614174001` | 对应检测项的ID |
| 3 | 样品编号 | SampleNumber | 是 | String | SN20240507001 | 冗余，便于核对 |
| 4 | 分析项目名称 | AnalysisItemName | 是 | String | pH检测 | 冗余，便于核对 |
| 5 | 分析时间 | AnalysisTime | 是 | Date | 2024-05-08 14:30 | 检测分析完成的时间 |
| 6 | 检测结果 | TestResult | 是 | String | 7.4 | 检测得到的结果值 |
| 7 | 量纲 | Unit | 是 | String | 无 | 检测结果的单位 |
| 8 | 检出限 | DetectionLimit | 否 | Float | 0.01 | 冗余，可选填 |
| 9 | 数据类型 | DataType | 是 | String | 实测值、推算值 | 数据的类型说明 |
| 10 | 分析状态 | AnalysisStatus | 是 | String | 成功、失败 | 分析过程的状态 |
| 11 | 最终结果 | FinalResult | 否 | String | 是、否 | 是否为最终结果，复测时使用 |

无人实验室可通过"质控数据推送接口"推送质控结果数据。该接口用于将质控样品的检测结果推送至LIMS系统。

| 1 | 数据ID | DataID | 是 | String | `123e4567-e89b-12d3-a456-426614174003` | 唯一标识质控数据的编号 |
| 2 | 测试项ID | TestItemID | 是 | String | `123e4567-e89b-12d3-a456-426614174001` | 对应检测项的ID |
| 3 | 质控类型 | QCType | 是 | String | 空白样、平行样、加标样、曲线 | 质控样品的类型 |
| 4 | 样品编号 | SampleNumber | 是 | String | SN20240507001 | 冗余，便于核对 |
| 5 | 分析项目名称 | AnalysisItemName | 是 | String | pH检测 | 冗余，便于核对 |
| 6 | 分析时间 | AnalysisTime | 是 | Date | 2024-05-08 14:30 | 质控样品分析完成的时间 |
| 7 | 检测结果 | TestResult | 是 | String | 0.0 | 质控样品的检测结果值 |
| 8 | 量纲 | Unit | 是 | String | 无 | 检测结果的单位 |
| 9 | 检出限 | DetectionLimit | 否 | Float | 0.01 | 更新后的检出限值 |
| 10 | 质控标准 | QcStandards | 是 | String | 39.00±2.90 | 质控标准值 |
